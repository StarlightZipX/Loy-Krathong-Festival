# ลอยกระทงออนไลน์ 3D - โหวตผู้เข้าประกวด (Loy Krathong Festival 3D)

เว็บแอปพลิเคชันโหวตกระทงออนไลน์แบบ 3 มิติด้วย **Three.js + React + TypeScript + Tailwind CSS + Firebase Firestore** รองรับการใช้งานทั้ง **PC, Tablet และ Smartphone**

## ฟีเจอร์หลัก
1. **ฉาก 3D ด้วย Three.js:** แม่น้ำเคลื่อนไหว, ดวงจันทร์เต็มดวงพร้อมแสงสะท้อนบนผิวน้ำ, ท้องฟ้าดวงดาว, บ้านทรงไทยยกใต้ถุน, วัด (อุโบสถหลังคาซ้อนชั้น) และเจดีย์สีทอง
2. **กระทงหลากสี 20 กระทงเริ่มต้น:** ลอยโคลงเคลงพร้อมแสงเทียนและธูป 3 ดอก (5 รูปแบบ: กระทงใบตองคลาสสิก, กระทงดอกบัวหลวง, กระทงกะลาประทีป, กระทงขนมปังสีรุ้ง, กระทงกลีบทองวิจิตร)
3. **ผู้คนเดินชมงาน 20 คน:** ตัวละคร 3D เดินชมบรรยากาศริมแม่น้ำ ท่าน้ำ และลานวัด
4. **ควบคุมมุมกล้องอิสระ:** หมุนฉาก (ลากเมาส์ / 1 นิ้ว), ซูมเข้า-ออก (ลูกกลิ้งเมาส์ / จีบ 2 นิ้วบนมือถือและแท็บเล็ต) พร้อมปุ่มลัดมุมกล้อง
5. **ถ่ายรูปและลดขนาดอัตโนมัติ (≤ 500 KB):** เปิดกล้องถ่ายรูปตัวเอง (หรืออัปโหลดรูปจากเครื่อง) ระบบย่อขนาดและบีบอัดรูปอัตโนมัติให้ไม่เกิน 500 KB ก่อนบันทึกลง **Cloud Firestore**
6. **แตะกระทงเพื่อโหวตแบบ Real-time:** แตะ/คลิกที่กระทงใดก็ได้เพื่อเปิด Popup แสดงรูปภาพเจ้าของ ชื่อ คำอธิษฐาน และกดโหวตอัปเดตคะแนนใน Firestore แบบ Real-time

## การตั้งค่า `.env`
คัดลอก `.env.example` เป็น `.env` แล้วใส่ค่า Firebase config (ขึ้นต้นด้วย `VITE_FIREBASE_*`)

## วิธีรันโปรเจกต์

```bash
# ติดตั้ง dependencies
npm install

# รันโหมดพัฒนา
npm run dev
```

หรือรันแบบ Production:

```bash
npm run build
npm start
```
